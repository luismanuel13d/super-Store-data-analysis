## SUPERSTORE Data Analysis

Proyecto de análisis de datos desarrollado utilizando Python, SQL, Excel y Power BI.

 # Descripción del proyecto

El objetivo de este proyecto es analizar un conjunto de datos de aproximadamente 9,800 filas, aplicando diferentes herramientas para realizar un proceso completo de análisis de datos.

🛠️ Herramientas utilizadas
Python: limpieza y transformación de los datos.
SQL: consultas y análisis de la información.
Excel: elaboración del mockup y preparación de la estructura del análisis.
Power BI: creación del dashboard y análisis visual de los datos.
🔄 Proceso del proyecto
Limpieza de datos: realizada con Python.
Consultas y análisis: realizadas mediante postgresql.sql.
Mockup: elaborado en Excel para definir la estructura visual.
Visualización: desarrollo del dashboard final en Power BI.
📁 Archivos

En este repositorio se incluirán los archivos utilizados durante las diferentes etapas del proyecto.

el Resultado ..... <

El proyecto busca integrar diferentes herramientas de análisis de datos en un flujo de trabajo completo, desde la limpieza de información hasta la visualización de resultados en Power BI.
